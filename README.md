# Тренажёр вопросов

Приложение, которое учит задавать вопросы на английском — от простого к сложному. Для тех, кто знает английский примерно на уровне B1, но путается в порядке слов, do / does / did и вежливых формах.

## Что внутри

- **Вводный тест** — 16 вопросов, по одному на модуль. Показывает, с какого модуля начать.
- **16 модулей** в четырёх уровнях. В каждом:
  - урок: правило, формулы с цветными частями вопроса, анимации «утверждение → вопрос», таблицы, лайфхаки и запоминалки, типичные ошибки;
  - мини-проверка из трёх вопросов;
  - тренажёр на 50 заданий шести типов: собрать из слов, выбрать слово, перевести, исправить ошибку, задать вопрос к выделенной части, придумать вопрос к ответу;
  - подсказки в три ступени: сначала разбор ошибки, потом формула с пропусками, потом ответ;
  - после каждого ответа — другие способы спросить то же самое, с озвучкой.
- **Итоговый экзамен** — 50 заданий из всех модулей и разбор по темам.

| Уровень | Модули |
|---|---|
| 1. Основа (A1–A2) | to be · do / does · did · модальные глаголы |
| 2. Специальные вопросы (A2) | вопросительные слова · what time / how much / how often · Continuous, Perfect, Future · вопрос к подлежащему · предлог в конце, What … like? |
| 3. Живая речь (B1) | альтернативные · отрицательные · разделительные (tags) · косвенные и вежливые · короткие реакции |
| 4. Продвинутый (B1+ / B2) | пассив · сложные случаи (Perfect Continuous, условные, used to) |

## Как запустить

Открой `index.html` в браузере — сервер и установка не нужны. Прогресс сохраняется в браузере (localStorage).

Для доступа по ссылке можно включить GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.

## Структура

```
index.html        каркас приложения, модули 1–2, проверка ответов
modules/m3.js …   модули 3–16: уроки, анимации и задания
  m16.js
```

Каждый модуль — объект `CONTENT.mN` с полями `title`, `idea`, `rules()`, `demos`, `check`, `tasks` и необязательной функцией `diagnose()` для разбора ошибок, характерных для этой темы.
